I recently started learning the Svelte framework, and this is one of my first projects created to demonstrate my basic understanding of Svelte and SvelteKit. I built a simple Color Preference Selector where users can select between Blue, Green, and Red, and the selected color is displayed dynamically on the page. While developing this project, I learned and implemented basic Svelte concepts such as creating and using components, passing data from a parent component to a child component using props, managing state with `$state()`, handling button click events, and updating the UI dynamically based on user interaction. This project is a small step in my journey of learning Svelte, and I plan to build more projects as I continue learning the framework.
